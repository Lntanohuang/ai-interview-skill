# 评分与报告规范

## 分项评分

针对能力地图中的每项能力使用相同的 0–4 级尺度，不输出缺乏校准依据的百分制总分、排名或录用概率。

| 等级 | 本次回答中的证据 |
| --- | --- |
| 0 | 已作答，且明确出现与该能力相关的关键错误；必须引用错误，并说明正确原则及理由 |
| 1 | 涉及主题，但表达笼统，关键步骤、个人行动或依据不足 |
| 2 | 有具体行动和基本合理的解释，但结果验证、取舍或边界不充分 |
| 3 | 有连贯的行动、理由和验证证据，能解释主要追问 |
| 4 | 在 3 的基础上，能分析限制、替代方案，并合理处理新的约束或情境 |
| 未评估 | 未问到、跳过、无回答或证据无法获得；不等同于 0 分 |

等级按岗位及初级/高级要求解释，不要求每个回答都有数字。非量化结果可用可观察的变化、反馈、产出或验证步骤支持。未实际完成的情境方案只证明分析思路，不能描述成已有业绩。数字属于学生自述，不宣称已外部核实。

每个已评分能力至少列一处逐字引用与回答 ID，再说明引用如何支持等级。若证据相互矛盾且未澄清，应降低结论确定性并标记待验证，不武断定性。可标记证据充分度为低/中/高，其含义是当前回答的覆盖与具体程度，不是统计置信度。提示后回答应注明，不能直接视为独立掌握。

## 报告模板

# 模拟面试练习报告

### 练习范围

- 目标岗位、JD 来源或通用假设、难度、模式。
- 已完成主问题与追问数，跳过/未覆盖内容。
- 说明：仅评价本次回答；简历和成果为用户自述。

### 分项表现

| 岗位能力 | 练习等级 | 回答证据（ID + 逐字短引文） | 判断理由与缺口 | 下一步练习 |
| --- | --- | --- | --- | --- |

未评估项保留在表中，写明原因。摘录应短而足以支持判断，不用大量引用填充篇幅。

### 关键问答复盘

选择 1–3 组最值得改进的问答，逐组列出：

1. 主问题与追问要点及 ID。
2. 用户原话及 ID。
3. 已展示的优点、追问后是否补足缺口、仍缺什么。
4. 基于原回答事实的改进结构。未知事实用 `[待补充：具体内容]`，绝不补造工具、职责或业绩数字；明确标注“表达示范，不是原话”。

### 优先改进建议

给出最多 3 个按优先级排列的建议，每项包含：对应证据、可执行动作、完成标准。例：“重新回答 Q1，交代本人动作、指标分母及一次验证方法；三项均能明确说明即完成这次练习。”避免“加强表达”“多练习”等无法执行的泛泛建议。

### 下一轮

给出一个针对首要缺口的重答问题，等待用户回答。重答后的对比引用 A1 与 A1-R1，更新相关分项，明确改进理由。

## 发布报告前检查

- 每处引文能在对应用户回答中逐字找到，ID 没有错位。
- 没有把 JD、简历、助手示范或提示内容当作学生回答证据。
- 每个分数与文字解释一致，跳过与未覆盖项未记 0 分。
- 建议与岗位要求及已发现缺口相连，示范没有添加虚构事实。
- 对话只有一题尚待作答，没有连续替学生完成问答。
