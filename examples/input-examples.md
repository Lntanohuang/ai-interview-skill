# 输入示例

以下经历、岗位与数据均为虚构教学材料，可替换为自己的匿名信息。复制任一输入即可开始；AI 应先给出能力地图和第一题，等待你作答。

## 示例一：数据分析实习生（含 JD）

```text
使用 $ai-interview 帮我练习面试。

目标岗位：电商数据分析实习生
岗位要求：
1. 使用 SQL 提取并清洗数据。
2. 分析用户转化漏斗，解释指标变化。
3. 用图表呈现结论，与业务团队沟通。

我的简历（匿名）：
- 统计学大三，学过概率统计和数据库。
- 课程项目：分析一个公开的模拟电商数据集，约 1 万条订单。
- 我负责用 SQL 去重、处理缺失值，用 Excel 做转化漏斗。
- 发现部分渠道转化率低，做了课堂汇报；没有参与真实业务上线。

练习设置：中文，校招难度，3 道主问题，每题最多追问 2 次。
请重点练习项目深挖与指标口径，一次只问一题，结束后引用我的回答形成报告。
```

## 示例二：新媒体运营实习生（暂无 JD）

```text
使用 $ai-interview。
目标岗位：新媒体运营实习生，暂时没有具体 JD，请标注通用岗位假设。
简历摘要：新闻学大二，运营校内读书社账号一个学期，参与选题和推文排版。
我独立写过 6 篇推文，平均阅读量约 300；组织过一次线上征文，有 20 人参与。
没有商业投放经验。
请用中文做 3 道主问题的练习，关注内容策划、数据复盘和协作。
回答不清楚时再追问，不要替我编造经历。
```

## 示例三：后端开发实习生（英文真实模拟）

```text
Use $ai-interview to run an interview in English.
Target role: Backend Engineering Intern.
JD: Java basics, REST APIs, SQL, and debugging.
Resume: Third-year computer science student. Built a course library system
with Spring Boot and MySQL. I implemented book search and borrowing APIs.
The project was tested locally by four classmates; it was not deployed to production.
Settings: 4 main questions, up to 2 follow-ups each, entry level.
Please save feedback until the end and cite my exact answers in the report.
```

## 空白输入模板

```text
使用 $ai-interview。
目标岗位：
岗位要求/JD：（没有可写“暂无”）
简历或匿名经历：
- 专业/学习阶段：
- 项目/实习/社团经历：
- 本人职责、方法、结果：
练习语言：（默认中文）
难度：（默认实习/校招）
主问题数量：（默认 5）
每题追问上限：（默认 2）
模式：（默认练习模式；可选结束后统一反馈）
重点或担心的问题：（可选）
```

## 练习中可以这样说

- “这题跳过。”
- “给我一个小提示，然后让我自己答。”
- “先结束，按现有回答给我阶段报告。”
- “我要重答 Q1，请比较改进前后。”
- “暂停，给我一份下次可以粘贴续练的进度摘要。”
